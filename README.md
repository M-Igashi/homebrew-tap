# Homebrew Tap

Personal Homebrew tap for my tools.

## Installation

```bash
brew tap M-Igashi/tap
```

## Available Casks

### markupsidedown

AI-era Markdown editor with live preview and Cloudflare integration.

```bash
brew install --cask markupsidedown
```

### mp3rgui

GUI for lossless MP3/M4A volume adjustment, a modern mp3gain replacement.

```bash
brew install --cask mp3rgui
```

## Available Formulas

### baken

Bake'n Deck: Rekordbox to CDJ prep toolkit with loudness gain, Key+BPM playlist sort, and CDJ-safe MP3 transcode. Replaces the former `headroom` formula.

```bash
brew install baken
```

### flipdf

Merge duplex-scanned PDFs into proper page order, for home scanners without auto-duplex.

```bash
brew install flipdf
```

### mp3rgain

Lossless MP3/M4A volume adjustment, a modern mp3gain replacement written in Rust.

```bash
brew install mp3rgain
```

### region-proxy

A CLI tool to create a SOCKS proxy through AWS EC2 in any region.

```bash
brew install region-proxy
```

## Updating

```bash
brew update
brew upgrade <formula>
```

## Uninstalling

```bash
brew uninstall <formula>
brew uninstall --cask <cask>
brew untap M-Igashi/tap
```
